- 学習後に残った失敗と、その型（根拠なしの質問に断定した / 根拠ありの質問に確認要求で逃げた / 形式の崩れ）：
回答の根拠がないにもかかわらず、断定的に回答したケースが2問あった。「成績はいつ出ますか」という質問には課題の提出期限を、「オフィスアワーは事前予約が必要ですか」という質問には開催日時を回答していた。いずれも needs_review: false としており、確認が必要な質問であると判断できていなかった。
- 知識を問う質問（セクション 6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：
学習前は4問すべてが format_error であったが、学習後は asserted が2問、needs_review が2問となり、JSON形式は改善した。
FAQに記載のない担当教員の名前と次回の講義テーマについては、適切に確認を求める回答が得られた。一方、最終課題の締切については、通常の課題提出期限を流用して誤って断定した。対照質問の「課題の提出期限」については、FAQに根拠があり、断定は適切であった。
この結果から、LoRA学習によって回答形式は改善したものの、回答の根拠の有無を適切に判断できないケースが残ることが確認された。
- 学習で変わったこと・変わらなかったこと：
LoRA学習によって、評価用21問に対する形式遵守率は9.5%から100%、内容正解率は0%から90.5%へ改善した。また、Training LossはStep 10の1.558からStep 40の0.014まで低下した。
一方、学習後もFAQに回答の根拠がない質問に対して、別のFAQ項目を流用して断定する誤回答が2問残った。今回の実験ではValidation Lossの推移を確認していないため、過学習の有無については判断できない。
以上から、回答形式の学習には高い効果が認められた一方、形式遵守率の向上が回答内容の正確性を保証するものではないことが確認された。

## 宿題

- 取り組んだレベル：発展
- 変えた設定やデータ：
講座の用語集58語から116件のQ&Aデータを生成し、元の演習で使用した架空FAQの教師データに代えてLoRA学習を実施した。モデルはQwen3.5-0.8B、学習率2e-4、LoRA rank 16、alpha 32とした。学習時間を考慮し、エポック数は3に設定した。
学習前後の比較には、学習時と異なる言い回しによる既知用語5問と、用語集にない3問を使用した。また、用語集の完全一致検索とも比較した。
- 結果（比較表や数字）：
  学習は3エポック、45ステップ、113.9秒で完了した。
  Training LossはStep 5の3.302からStep 45の1.126へ低下した。

  | 評価対象 | 学習後の結果 |
  | --- | --- |
  | トークン | 入出力の合計文字数と説明し、定義を混同 |
  | コンテキストウィンドウ | 用語集の定義に近い回答 |
  | プレートテクトニクス（用語集外） | LLMに関する無関係な回答 |

  学習後も定義の混同や誤回答が見られた。
一方、用語集の完全一致検索では、登録された定義をそのまま取得でき、未登録用語には「用語集に記載がありません」と返した。
なお、評価は既知用語5問と用語集外3問に限られ、回答精度の定量的な評価は実施していない。
- ファインチューニングが向く場面・向かない場面についての考察：
ファインチューニングは回答形式や表現の調整に適している一方、今回の実験では定義の混同や誤回答が残った。正確な定義の提示や情報更新が重要な場合は、用語集を直接検索する方式が有利と考えられる。ただし、今回実装した完全一致検索では、質問の言い換えに対応できないという課題がある。
今回の取り組みで改善できる点としては、エポック数による回答精度と学習時間の関係を比較し、計算コストに見合った学習条件を検討することが挙げられる。
